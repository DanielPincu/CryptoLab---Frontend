# CryptoLab – Frontend (Paper Crypto Trading App)

CryptoLab is a paper trading platform for cryptocurrencies.  
This frontend is the client application that connects to the CryptoLab backend API and allows users to interact with the platform through a modern web interface.

Users can register, log in, view live crypto prices, manage a watchlist, and simulate buy/sell trades without using real money.

This frontend is built as part of a bachelor exam project and focuses on:

- Clean and responsive UI  
- Real-time data visualization  
- State management and API integration  
- Authentication flows (JWT)  
- Maintainable frontend architecture  

---

## 🚀 Features

- User registration & login  
- JWT-based authentication  
- Live crypto prices (via backend WebSocket proxy)  
- Paper trading (buy / sell crypto)  
- Portfolio & open positions  
- Market history charts  
- Favorites / watchlist  
- Responsive layout (desktop & mobile)  

---

## 🧱 Tech Stack

- React  
- TypeScript  
- Vite  
- Axios (API communication)  
- WebSockets (real-time prices via backend)  
- CSS / Tailwind / Styled Components (adjust to what you use)
